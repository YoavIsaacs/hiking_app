# Step 0.3 — React app

Branch: `step/0.3-react-app` · Phase: 0 · Status: briefing (blocked on Open decision 1)

## Goal
`web/` is a strict-TypeScript React app with a router and TanStack Query whose one page shows the API's status
and version from `/health` (with loading and error states), tested with Vitest + RTL + MSW and a Playwright
smoke test against the real local API, gated in CI by `web-test`, `e2e` and CodeQL for JS/TS.

## Open decisions (manager)
1. **`.env` files — roadmap vs CLAUDE.md.** The checklist says "`.env.development` and `.env.production`"
   (Vite mode files, committed). CLAUDE.md says "Never commit … `.env*` files", and 0.1's `.gitignore` ignores
   `.env*`. Options:
   - **A (recommended):** commit exactly `web/.env.development` and `web/.env.production`, holding only public
     `VITE_*` values (anything `VITE_*` ships in the bundle anyway, so it can never be a secret). Amend the
     CLAUDE.md Git rule to name these two as the only allowed exception, and add `.gitignore` negations.
     Production `VITE_API_URL` is a placeholder until 0.5 knows the Cloud Run URL.
   - **B:** deviate from the roadmap: no committed env files; `VITE_API_URL` defaults to
     `http://localhost:8000` in code and CI/deploy sets it. Keeps CLAUDE.md as is, but drops a checklist item
     (needs your deferral).
2. (Informational, no action) No visual identity exists yet. 0.3 uses unstyled/system defaults and removes
   the Vite template's purple CSS; a graphic-designer pass is planned before the first Phase 1 screen.

  all three projects locally and in CI `e2e`.
- CodeQL JS/TS → 0 open alerts on the PR and on `main`.

## Process (from 0.2 lessons — see `PROGRESS.md` "Process rules learned")
- Frontend commits the typed stub first; QA commits red tests against it and shows assertion failures; then
  frontend implements. No `--no-verify`.
- Every agent stages by path; no `git add -A`, `git stash`, or formatters over files it doesn't own.
- Coverage: set a Vitest coverage threshold in `vitest.config.ts` (frontend proposes; 0.3 baseline ≥ 80% lines
  unless the roadmap says otherwise — tech lead approves; never lowered later to get green).
