# Step 0.4 — Generated API client

Branch: `step/0.4-generated-api-client` · Phase: 0 · Status: build

## Goal
The web app talks to the API only through an openapi-fetch client typed by `web/src/api/schema.d.ts`, which
`pnpm gen:api` generates from FastAPI's OpenAPI schema (exported without a server); `tsc` breaks on contract
drift, and the `api-contract` CI job fails whenever the committed client is out of date with the API.

## Checkpoint
**Checkpoint:** 0 hand-written request or response types in `web/`; the contract job fails when you break it on purpose

How it will be measured:
- Grep `web/src` (excluding `schema.d.ts`): no `interface`/`type` describing an API request or response, and no
  local aliases of API types; the 0.3 `Health` interface is gone; the hand-written `isHealth` is replaced by a
  field-guard map typed from `components['schemas']['HealthResponse']` (ADR 0001 §4), so drift breaks `tsc`.
- Locally: change a field in `HealthResponse` without regenerating → `just gen-api && git diff --exit-code`
  fails and `tsc` fails on `__typecheck__.ts`/Home page.
- In CI: tech lead pushes a deliberate-break commit to the PR branch → `api-contract` red (run link
  recorded), then reverts → green. The break and revert stay in history as evidence.
- `api-contract`, `web-test`, `api-test`, `lint`, `e2e` green on the PR and on `main` after merge.
