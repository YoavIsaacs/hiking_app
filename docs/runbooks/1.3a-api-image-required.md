# Runbook 1.3a — Mark `api-image` as a required check (manager)

Source: `docs/steps/1.3a.md` (manager-approved new required check, 2026-11-01).
Commands are **PowerShell** and need the GitHub CLI logged in as the repo owner (`gh auth status`).
Repo: `YoavIsaacs/hiking_app`; ruleset `main` has id `25060155` (runbook 0.6).

Do this **after** `api-image` has reported once on the 1.3a PR (a check that has never run cannot be picked in the
UI picker, and requiring a name that never reports blocks every PR). A skipped `api-image` (no `api/**` change)
counts as passing, so web-only and docs-only PRs are not blocked.

## 1. Add the check

UI: Settings > Rules > Rulesets > `main` > Require status checks to pass > Add checks > `api-image` > Save.

CLI (idempotent: adds `api-image` only if absent, keeps everything else; GET, edit, PUT):

```powershell
$repo = "YoavIsaacs/hiking_app"
$id = 25060155
$rs = gh api "repos/$repo/rulesets/$id" | ConvertFrom-Json
$rule = $rs.rules | Where-Object { $_.type -eq "required_status_checks" }
if (-not ($rule.parameters.required_status_checks | Where-Object { $_.context -eq "api-image" })) {
  $rule.parameters.required_status_checks += [pscustomobject]@{ context = "api-image"; integration_id = 15368 }
}
$body = [pscustomobject]@{
  name = $rs.name; target = $rs.target; enforcement = $rs.enforcement
  bypass_actors = @($rs.bypass_actors); conditions = $rs.conditions; rules = @($rs.rules)
}
$body | ConvertTo-Json -Depth 20 | Set-Content -Encoding utf8 ruleset-api-image.json
gh api -X PUT "repos/$repo/rulesets/$id" --input ruleset-api-image.json
```

`integration_id` 15368 is GitHub Actions, the same value the other checks use (runbook 0.6).

## 2. Verify

Expect the earlier contexts plus `api-image` (and still `enforcement: active`):

```powershell
gh api "repos/YoavIsaacs/hiking_app/rules/branches/main" --jq '.[] | select(.type=="required_status_checks") | [.parameters.required_status_checks[].context] | sort'
gh api "repos/YoavIsaacs/hiking_app/rulesets/25060155" --jq '{enforcement, bypass_actors}'
```

Real-path check: open any PR that touches only `web/` or `docs/`; its `api-image` check must show **Skipped** and
the PR must still be mergeable. A PR touching `api/` must show `api-image` running and blocking until green.
