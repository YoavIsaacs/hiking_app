# Step 0.1 — Repo and tooling

Branch: `step/0.1-repo-tooling` · Phase: 0 · Status: PR

## Goal
A fresh clone of the public monorepo installs, lints, tests and runs placeholder `api/` and `web/` apps with
a few documented commands, and every PR is gated by a `lint` job running pre-commit on all files.

## Checklist
Copied verbatim from `docs/roadmap/phase-0.md`. Owner in brackets.

Agents this step uses: `backend-expert` (api/ scaffold), `frontend-expert` (web/ scaffold), `devops` (repo
tooling, CI, Dependabot, justfile, README, PR template), `qa` (verify + checkpoint), `reviewer`.
Skipped: `architect` (no module boundary or contract yet; stack is fixed in CLAUDE.md), `ux-expert` and
`graphic-designer` (no user-facing screen), `mobile-expert` (Phase 4+).
Tests-first by `qa` skipped: pure config/infra with no product behaviour. The only tests are trivial

## Checkpoint
**Checkpoint:** a fresh clone runs both apps locally in ≤ 3 commands each; pre-commit passes on 100% of files; a commit containing a fake API key is blocked

How it will be measured:
- `git clone` into a temp dir; count commands from clone to a running `dev-api` and `dev-web` (each ≤ 3, e.g. `just install` → `just dev-api`); confirm each responds (HTTP 200 locally).
- `pre-commit run --all-files` exits 0 locally and in the `lint` job on the PR.
- "Runs both apps" here means the placeholders; the real apps are re-checked at 0.2 and 0.3.
- Fake-API-key part: **deferred by manager**.

## Decisions and deviations
- 2026-10-13 — Placeholder `api/` and `web/` in 0.1 so the hooks, `just test` and the run commands have
  something real to act on; full "runs both apps" is re-verified at 0.2/0.3. Manager approved.
- 2026-10-13 — Repo is public; license is MIT. Manager.
- 2026-10-13 — Secret scanning + push protection and the "fake API key is blocked" verification are
  **deferred** until secrets become relevant (earliest 0.5 Deployment). The `detect-private-key` pre-commit
  hook stays in. Manager. Consequence: 0.1 closes with this part of the checkpoint marked deferred in `PROGRESS.md`.
- 2026-10-13 — The Vite template now ships oxlint; replaced with ESLint (in the stack, named in the hook
  item). Standard companions added: `@eslint/js`, `typescript-eslint`, `eslint-plugin-react-hooks`,
  `eslint-plugin-react-refresh`, `globals`, `eslint-config-prettier`. Tech lead.
- 2026-10-13 — `.gitattributes` (`* text=auto eol=lf`) added by devops beyond the checklist; accepted
  (prevents CRLF drift on Windows). Tech lead.
- 2026-10-13 — `tsc` pre-commit hook added for `web/` (reviewer finding): without it nothing type-checks
  the web app until 0.3's `web-test`, and strict types are non-negotiable. Tech lead.
- 2026-10-13 — Reviewer nits on the `web/` placeholder (explicit `"strict": true`, `<title>`, leftover Vite
  template CSS and `icons.svg`, `toBeTruthy` in the placeholder test, `tseslint.config` → `defineConfig`)
  **deferred to 0.3**, which rewrites the app, tsconfig and test setup. Not worth a round on a placeholder. Tech lead.
