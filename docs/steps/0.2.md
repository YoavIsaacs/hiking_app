## Goal

SHA, origin-restricted CORS, request-ID JSON logging and a container image — gated in CI by `api-test`

## Decisions and deviations
- 2026-10-13 — `--disable-socket` on Windows: Starlette's `TestClient` opens a loopback socketpair on the
  Windows event loop and fails under bare `--disable-socket`. Use `--disable-socket --allow-hosts=127.0.0.1`
  (loopback only; outbound network still blocked, so the standard holds). Tech lead.
- 2026-10-13 — `httpx` vs `httpx2`: Starlette deprecates `httpx` for `TestClient`. Stay on `httpx` (in the
  stack); add a single targeted `filterwarnings` entry for that one deprecation with a one-line reason.
  `httpx2` would be a new dependency → only with an ADR and manager approval. Tech lead.
- 2026-10-13 — Checkpoint says "3 passing tests"; the checklist names 5. All 5 are required; ≥ 3 is the floor. Tech lead.
- 2026-10-13 — The 0.1 placeholder (`app.main:app`, `GET /`, `tests/test_placeholder.py`) is replaced by the
  factory; `just dev-api` and the README move to `--factory`. Placeholder test is removed by QA. Tech lead.
