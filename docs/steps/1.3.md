# Step 1.3 — Elevation backfill

Branch: `step/1.3-elevation-backfill` · Phase: 1 · Status: tests (stub)

## Goal
When an uploaded GPX has no usable elevation (missing, partly missing or implausible, ADR 0004 §3.1 step 8),
`POST /v1/routes/parse` looks it up from Open-Meteo's elevation API for the simplified points only (≤ 5 calls per
route), recomputes gain/loss on them, and returns `elevation_source = "lookup"`. If the lookup fails, the route still
comes back, flagged, with no 500. All of this is tested offline against recorded responses.

## Agents
`architect` (ADR 0005: Open-Meteo elevation integration, the parse → backfill → summarise seam, contract change for
the warning, call budget vs retry, smoothing parameters for looked-up data, recorded-fixture format) → `backend-expert`
contract stub → `qa` records responses + red tests → `backend-expert` build + `just gen-api` → `devops` (1.2 carry:

Skipped: ux-expert / graphic-designer (no screen; 1.10 shows the warning), frontend (only the regenerated

## Decisions and deviations
- 2026-10-20 — 1.2 follow-ups folded into 1.3 (list above), tech lead: same code area, small.
- 2026-10-20 — Recording real Open-Meteo responses is a one-off, manual, out-of-pytest call by QA; the recordings
  and how they were made are committed. Unit tests stay offline. Tech lead.
- 2026-10-20 — ADR 0005 accepted (tech lead). Within the brief, so no manager decision:
  - "1 retry" = **one retry per route**, shared by its batches; no-elevation routes simplify to **≤ 400 points**
    (≤ 4 batches + 1 retry = ≤ 5 calls). Schema still allows 2..500.
  - Client path **`app/clients/elevation.py`**, not the roadmap's `app/routes/elevation.py` (that file is the pure
    smoothing module; `app/routes/` stays I/O-free). Orchestration in `app/services/route_parse.py`.
  - Failure warning is a new required `RouteSummary.warnings: list[ApiWarning]` (`elevation_unavailable`) → contract
    change, `just gen-api`.
  - Lookup smoothing starts at 1.2's 20 m / 9.5 m; QA's recorded Tel Hadid run confirms or triggers ADR 0005 §3's grid.
  - `httpx` moves from dev to runtime dependencies (already locked; roadmap names it).
