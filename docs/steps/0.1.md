# Step 0.1 — Repo and tooling

Branch: `step/0.1-repo-tooling` · Phase: 0 · Status: build

## Goal
A fresh clone of the public monorepo installs, lints, tests and runs placeholder `api/` and `web/` apps with
a few documented commands, and every PR is gated by a `lint` job running pre-commit on all files.

## Checkpoint
**Checkpoint:** a fresh clone runs both apps locally in ≤ 3 commands each; pre-commit passes on 100% of files; a commit containing a fake API key is blocked

How it will be measured:
- `git clone` into a temp dir; count commands from clone to a running `dev-api` and `dev-web` (each ≤ 3, e.g. `just install` → `just dev-api`); confirm each responds (HTTP 200 locally).
- `pre-commit run --all-files` exits 0 locally and in the `lint` job on the PR.
- "Runs both apps" here means the placeholders; the real apps are re-checked at 0.2 and 0.3.
- Fake-API-key part: **deferred by manager**.
